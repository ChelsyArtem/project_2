# Анализ строительной отрасли на основе данных ФНС

Учебный проект по сбору, обработке и анализу данных российских компаний строительной отрасли.

Цель проекта — сформировать датасет компаний, получить их финансовые показатели из открытых данных ФНС, проанализировать динамику прибыли и визуализировать географическое распределение крупнейших компаний по выручке.

## О проекте

В качестве исходных данных используется реестр организаций. Из него отбираются действующие организации, после чего по ИНН выполняется получение дополнительной информации с сайта Федеральной налоговой службы.

Полученные данные объединяются в единый датасет, который используется для дальнейшего анализа.

Основные этапы проекта:

- обработка исходного реестра организаций;
- фильтрация действующих организаций;
- получение информации о компаниях по ИНН;
- сбор финансовых показателей за доступные годы;
- расчёт показателя `ubita` на основе данных финансовой отчётности;
- расчёт динамики чистой прибыли;
- анализ распределения компаний по темпам роста прибыли;
- определение 500 компаний с наибольшей выручкой;
- геокодирование адресов компаний;
- построение интерактивной карты.

## Источник данных

Основным внешним источником данных является официальный портал бухгалтерской отчётности ФНС — `bo.nalog.gov.ru`.

Из него получаются:

- идентификатор организации;
- ИНН;
- краткое наименование;
- адрес;
- данные финансовой отчётности по годам;
- показатели прибыли;
- выручка.

## Структура проекта

Проект состоит из нескольких этапов.

### HW_01 — сбор и подготовка данных

На первом этапе обрабатывается исходный Excel-файл с реестром организаций.

Из реестра исключаются организации, у которых заполнена дата исключения из реестра.

Для каждой организации выполняются запросы к API портала ФНС. Полученная информация используется для формирования единого датасета.

Для каждого доступного года сохраняются финансовые показатели и рассчитываются значения:

```text
ubita = current2300 - previous2300
profit = current2500 - previous2500
```

Результат сохраняется в файл `final_dataset.xlsx`.

### HW_02 — анализ динамики прибыли

На втором этапе анализируется изменение чистой прибыли компаний.

Для сравнения используются значения прибыли за 2025 год и за 2021 год.

Рассчитывается относительное изменение:

```text
Рост, % = (Прибыль_2025 - Прибыль_2021) / Прибыль_2021 × 100
```

После фильтрации данных строится столбчатая диаграмма, показывающая количество компаний с различными темпами изменения прибыли.

### HW_031 — подготовка данных для карты

На этом этапе формируется отдельный датасет компаний для географического анализа.

Компании сортируются по выручке, после чего выбираются 500 организаций с наибольшим значением `gainSum`.

Результат сохраняется в `map_dataset.xlsx`.

### HW_032 — географическая визуализация

Для адресов выбранных компаний выполняется геокодирование с использованием Nominatim.

На основе полученных координат создаётся интерактивная карта с помощью Folium.

Для каждой компании на карте отображаются:

- название;
- адрес;
- местоположение.

Готовая карта сохраняется в файл:

```text
map_500.html
```

- сбора данных из внешнего API;
- обработки и очистки данных;
- работы с финансовыми показателями;
- формирования датасетов;
- анализа и визуализации данных;
- геокодирования;
